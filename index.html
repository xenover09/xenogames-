FAQ

Questions, answered.

What is a game mashup?
A mashup runs content from one game inside another — a character, a world, mechanics, or the whole game. Some are simple ports, others rebuild entire engines. Here, each one is packaged so it installs with one click.
Do I need to know modding or coding?
No. If you can press a Play button, you can play every mashup in the library. All the technical steps — versions, loaders, file placement — happen automatically.
Is it safe for my games and PC?
Every file is verified (SHA-256) before it goes into the library. The launcher backs up any game file it touches, rolls back failed installs, and uninstalling removes everything cleanly.
Which games are supported?
The library keeps growing — check the grid above for what's available right now. New mashups and ports are added regularly, and the community votes on what comes next.
Does it work on my PC?
The launcher targets Windows 10 and 11. Each mashup lists what it needs; if your PC runs the base games, it runs the mashup.
Is this affiliated with the game publishers?
No. Xeno Games is a fan project and is not affiliated with, endorsed by, or connected to any game publisher. All games, titles and artwork belong to their respective owners.
